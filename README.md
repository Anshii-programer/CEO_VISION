## Installation

Clone the repository

```bash
git clone https://github.com/Anshii-programer/CEO_VISION.git
```

Go inside project

```bash
cd CEO_VISION
```

Install root packages

```bash
npm install
```

Install frontend packages

```bash
cd frontend
npm install
```

Install backend packages

```bash
cd ../backend
npm install
```

Create `.env`

```env
PORT=5000
```

Go back to root

```bash
cd ..
```

Run project

```bash
npm run dev
```

Frontend

http://localhost:5173

Backend

http://localhost:5000
